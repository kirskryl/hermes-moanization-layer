# Hermes Moanaization Layer

Переносимый слой для чистого Hermes Agent: Telegram UX, русский интерфейс, ChatGPT OAuth и локальное распознавание русской речи.

Он не содержит личных данных, токенов, подключений к чужим ботам, внешних API-ключей, CRM, заметок, календарей, почты, Telethon, Botovod, навыков владельца или механизмов отправки от личного аккаунта.

## Что устанавливается

- склейка соседних текстов, фото и альбомов в одно задание через тихое окно 2 секунды;
- очередь входящих сообщений вместо прерывания текущей задачи;
- русские собственные сообщения Hermes и чистые cron-отчёты;
- `/models` как алиас `/model` и кнопки только для GPT Sol 6, Terra 6.1 и Luna 6;
- основной GPT через OpenAI Codex OAuth, то есть через подписку ChatGPT; default — Luna 6;
- создание и редактирование изображений через `gpt-image-2-medium` и тот же ChatGPT OAuth, без отдельного API-ключа;
- ежедневный сброс выбора модели чата на Luna в 23:59 часового пояса сервера;
- локальный голосовой маршрут GigaAM-v3 `e2e_rnnt` → faster-whisper `base` fallback.

## Что нужно до установки

1. Чистая инсталляция Hermes Agent на Linux с работающим `hermes-gateway`.
2. Python 3.10+, `ffmpeg`, systemd и не менее 4 ГБ свободной RAM. GigaAM использует примерно 1.7 ГБ RAM во время распознавания.
3. Свой Telegram-бот и его токен, заданный пользователем в штатной конфигурации Hermes.
4. Своя подписка ChatGPT: после установки пользователь завершает OAuth в браузере командой `hermes auth add openai-codex --browser`.

## Накатка

```bash
git clone https://github.com/OWNER/hermes-moanization-layer.git
cd hermes-moanization-layer
./scripts/install.sh
```

Скрипт не подключает платный резервный провайдер по умолчанию. Он предлагает DeepSeek Flash как добровольный fallback с собственным ключом пользователя, а также спрашивает подтверждение перед загрузкой локальных весов моделей и установкой systemd-таймера. Подробности и откат: [docs/INSTALL.md](docs/INSTALL.md).

Если у Hermes уже есть `SOUL.md`, скрипт не перезаписывает его без отдельного ответа пользователя; рядом сохраняется нейтральный шаблон для ручного merge.

Перед установкой пользователь задаёт имя агента, грамматическую форму речи, обращение на «ты/вы», тон, длину ответов, инициативность и свободное правило стиля. Эти значения остаются в локальном `SOUL.md` и не попадают в репозиторий.

## Принципы безопасности

- Все ключи остаются в `~/.hermes/.env` конкретного пользователя и игнорируются Git.
- Аудио распознаётся на сервере пользователя; GigaAM и Whisper не отправляют запись во внешний API.
- Патчи исходников Hermes проверяют якоря и прекращают установку, если версия Hermes несовместима.
- В пакете нет автоматического доступа к файлам, браузеру, почте, заметкам, календарю или сторонним ботам.

Лицензии компонентов: GigaAM-v3 — MIT, faster-whisper — MIT. Условия ChatGPT-подписки определяет OpenAI.
