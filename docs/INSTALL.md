# Установка и проверка

## Перед запуском

Подключите свой Telegram-бот штатными средствами Hermes. Токен, allowlist и `home_channel` не входят в этот репозиторий. Затем завершите вход в ChatGPT:

```bash
hermes auth add openai-codex --browser
```

Этот вход использует подписку ChatGPT. Он не требует OpenAI API key. Пакет не настраивает DeepSeek, OpenRouter или иной биллинговый API.

Генерация и редактирование изображений включаются через тот же вход: `openai-codex/gpt-image-2-medium`. Отдельный ключ OpenAI для неё не нужен.

## Необязательный резерв модели

По умолчанию резервный провайдер отключён. Во время установки можно включить DeepSeek Flash как автоматический fallback для технического сбоя основной модели и обычного текстового отказа. Для этого пользователь сам заранее создаёт ключ DeepSeek и добавляет в `~/.hermes/.env` строку `DEEPSEEK_API_KEY=…` с правами файла `600`.

Когда срабатывает DeepSeek fallback, контекст конкретной задачи передаётся DeepSeek. Не включайте его для задач, которые нельзя передавать этому провайдеру.

Нужен другой поставщик — его можно задать вручную штатным `fallback_providers` Hermes после установки. Пакет не записывает ключи, не создаёт аккаунты и не включает платный fallback без явного выбора.

## Установка

`./scripts/install.sh` меняет только пользовательскую конфигурацию Hermes, кладёт слой в `~/.hermes/moanaization` и создаёт резервные копии исходников Hermes при первом применении overlay. Сценарий спрашивает отдельно:

- имя агента, форму речи, обращение, тон, длину ответа, инициативность и свободное описание стиля; из них собирается локальный `SOUL.md`;
- заменить ли существующий `SOUL.md` собранным профилем; при замене исходный файл сохраняется рядом;
- подключить ли DeepSeek Flash как автоматический fallback при техническом сбое или обычном текстовом отказе основной модели; ключ пользователь добавляет локально заранее и может не подключать;
- поставить ли user-level systemd-таймер ежедневного сброса модели; он не требует `sudo`.
- пройти ли по добровольным интеграциям: каждый пункт задаётся отдельно и сохраняется локально в `~/.hermes/moanaization/INTEGRATIONS.md` с правами `600`.

Локальные GigaAM и Whisper устанавливаются всегда: это базовый голосовой стек слоя, не платная опция и не облачная интеграция.

Мастер интеграций спрашивает о Drive/Docs/Sheets, почте, календаре и Reminders, заметках, локальном коннекторе к компьютеру, Telegram-канале, личном Telegram/Telethon, сайте и публичных материалах, CRM, GetCourse, ботах, контентных навыках, Zoom/SumKit, браузере, серверном и платёжном режиме. Для каждого выбранного пункта он сохраняет только назначение и комментарий владельца. Пароли, токены, cookie, ключи и коды 2FA не вводятся в установщик: для них используется штатный OAuth или другой безопасный способ конкретной интеграции.

Повторный запуск мастера сохраняет уже выбранные пункты и позволяет дополнить их. Комментарий с признаками секрета или длинной непрозрачной строкой не сохраняется.

Если на сервере меньше 4 ГБ свободной RAM, не устанавливайте GigaAM: оставьте только Whisper или увеличьте ресурсы сервера.

## Smoke-проверка

```bash
~/.hermes/moanaization/overlay/apply_all.sh --check
systemctl is-active hermes-gateway
systemctl --user list-timers hermes-luna-reset.timer
```

В Telegram отправьте короткий текст и следом фото в пределах двух секунд: агент должен получить одно объединённое задание. Выполните `/models`: должны отобразиться Sol 6, Terra 6.1 и Luna 6. Отправьте голосовое: в логе Gateway должна появиться строка о локальном STT command.

Пока агент занят, отправьте новую короткую текстовую задачу. После тихого окна она должна один раз ответить: `Принято, поставлено в очередь.` Затем завершить текущую задачу и начать следующую.

На headless-сервере user-level timer продолжит работать после выхода владельца, если включён linger для системного пользователя. Установщик проверяет это и выводит команду для администратора, если она нужна.

## После обновления Hermes

Исходники Hermes могут быть заменены обновлением. Повторите:

```bash
~/.hermes/moanaization/overlay/apply_all.sh --apply
sudo systemctl restart hermes-gateway
```

Если якорь overlay не найден, скрипт завершится с ошибкой и ничего не изменит. Сначала адаптируйте патч к новой версии Hermes.

## Откат

Удалите созданные файлы `*.orig-moanaization-*` рядом с соответствующими исходниками Hermes, вернув их на место вручную после проверки diff. Затем удалите systemd-таймер, если он был установлен, и перезапустите Gateway. Не удаляйте `~/.hermes/.env`: там могут находиться собственные секреты пользователя.
