# Установка и проверка

## Перед запуском

Подключите свой Telegram-бот штатными средствами Hermes. Токен, allowlist и `home_channel` не входят в этот репозиторий. Затем завершите вход в ChatGPT:

```bash
hermes auth add openai-codex --browser
```

Этот вход использует подписку ChatGPT. Он не требует OpenAI API key. Пакет не настраивает DeepSeek, OpenRouter или иной биллинговый API.

## Установка

`./scripts/install.sh` меняет только пользовательскую конфигурацию Hermes, кладёт слой в `~/.hermes/moanaization` и создаёт резервные копии исходников Hermes при первом применении overlay. Сценарий спрашивает отдельно:

- заменить ли существующий `SOUL.md` нейтральным шаблоном; при замене исходный файл сохраняется рядом;
- загрузить ли локальные веса GigaAM и Whisper;
- поставить ли systemd-таймер ежедневного сброса модели.

Если на сервере меньше 4 ГБ свободной RAM, не устанавливайте GigaAM: оставьте только Whisper или увеличьте ресурсы сервера.

## Smoke-проверка

```bash
~/.hermes/moanaization/overlay/apply_all.sh --check
systemctl is-active hermes-gateway
systemctl list-timers hermes-luna-reset.timer
```

В Telegram отправьте короткий текст и следом фото в пределах двух секунд: агент должен получить одно объединённое задание. Выполните `/models`: должны отобразиться Sol 6, Terra 6.1 и Luna 6. Отправьте голосовое: в логе Gateway должна появиться строка о локальном STT command.

## После обновления Hermes

Исходники Hermes могут быть заменены обновлением. Повторите:

```bash
~/.hermes/moanaization/overlay/apply_all.sh --apply
sudo systemctl restart hermes-gateway
```

Если якорь overlay не найден, скрипт завершится с ошибкой и ничего не изменит. Сначала адаптируйте патч к новой версии Hermes.

## Откат

Удалите созданные файлы `*.orig-moanaization-*` рядом с соответствующими исходниками Hermes, вернув их на место вручную после проверки diff. Затем удалите systemd-таймер, если он был установлен, и перезапустите Gateway. Не удаляйте `~/.hermes/.env`: там могут находиться собственные секреты пользователя.
