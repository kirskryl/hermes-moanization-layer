# Необязательный content-pack

Базовая накатка не устанавливает контентные навыки. Аудит локальных навыков Моаны показал, что текущие варианты завязаны на личный Mac, каналы, прокси, внешние аккаунты, закрытые методологии или собственные сервисы.

Для чистого Hermes можно включить только уже встроенные нейтральные навыки по желанию пользователя: `grounded-citations`, `document-to-action-items`, `meeting-action-items`, `pdf`, `docx`, `xlsx`, `github`, `codebase-inspection`, `systematic-debugging` и `test-driven-development`.

Отдельный публичный content-pack появится только после переписывания каждого переносимого навыка без исходных путей, персональных данных, аккаунтов, ключей и частных правил. Ничего из локальных навыков Моаны не копируется автоматически.
