# Установка через Telegram

Голому Hermes можно отправить ссылку на репозиторий и текст:

> Склонируй этот репозиторий в отдельную папку, прочитай README и docs/INSTALL.md. Примени `scripts/install.sh`. Не создавай платные аккаунты и не добавляй резервного провайдера без моего выбора. Перед установкой задай мне вопросы профиля агента по одному.

Это работает при условиях:

1. У Hermes включены инструменты terminal и file, а у хоста есть Git, Python 3.10+, `ffmpeg` и доступ к GitHub.
2. Пользователь сам настроил Telegram-бота в чистом Hermes.
3. После накатки пользователь сам завершает ChatGPT OAuth в браузере: `hermes auth add openai-codex --browser`.
4. Для systemd-таймера у агента есть право `sudo`; без него остальные функции слоя всё равно работают.

Установщик останавливается на вопросах имени, формы речи, обращения, тона, длины и стиля. Он также спрашивает про загрузку локальных голосовых моделей, замену существующего `SOUL.md`, таймер и добровольный DeepSeek fallback.

Overlay-патчи проверяют структуру исходников Hermes. При несовместимой версии установка прекращается до изменения исходников; агент должен сообщить об этом и не подбирать обходной путь без согласования.
